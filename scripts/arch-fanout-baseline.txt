# Architecture gates outside src/arch/: the census
# scripts/check-arch-fanout.sh ratchets.
#
# Each row is `<file under src/> <occurrences>  # <reason>`: how many times that
# file names `x86_64`, `aarch64`, or `riscv64` in a `target_arch` gate (with
# line comments stripped first), and why it names one at all.
#
# A row's reason is one of exactly two things, and the gate refuses a row that
# gives neither:
#
#   * `fact:` — a fact about the machine.  An ABI record only one architecture
#     has, a driver for hardware only one machine has.  A fourth architecture
#     decides what it does here; there is nothing to move behind a shim.
#   * `gap:` — a question the architecture should be answering.  The fix is to
#     move it behind `src/arch/`, and the row is the record of the work left.
#
# The gate fails when a count rises (printing the row's own reason, because a
# reason that covered the old count may not cover the new one), when a row
# shrinks without the census being re-recorded, when a file the census found
# has no row, and when a row has no reason.
#
# Re-record with `sh scripts/check-arch-fanout.sh --record` in every change
# that moves a gate; a record keeps each row's reason.  The pair on the line
# below this header is files first, then occurrences; the number to drive down
# is the `gap:` rows, not the total.
#
